Como usar o Midjourney: Guia para Iniciantes

Por TheAIStackies • 18 de Janeiro, 2026

O Midjourney é uma das ferramentas mais poderosas de IA generativa, mas ele pode parecer intimidador no começo porque funciona dentro do Discord.Aqui está um guia prático para você começar a criar imagens incríveis agora mesmo.

Como começar

  • Entre no Discord: Acesse o site oficial do Midjourney e clique em "Join the Beta" para ser redirecionado ao servidor do Discord.
  • Encontre uma sala: No menu lateral, entre em qualquer canal chamado #newbies-XX (ex: newbies-42).
  • Dê o comando inicial: Digite /imagine e pressione espaço. O campo prompt aparecerá; é lá que você descreve sua imagem.

Comandos essenciais

Além do comando de criação, existem outros fundamentais para gerenciar sua conta.

  • /imagine: O comando principal para gerar imagens.
  • /settings: Abre um menu visual para configurar a versão do modelo (ex: v6), o nível de estilização e o modo de velocidade.
  • /describe: Você faz o upload de uma imagem e a IA sugere 4 prompts que descreveriam aquela foto. Ótimo para aprender!
  • /blend: Permite misturar de 2 a 5 imagens para criar algo novo baseado nelas.

Anatomia de um Prompt "Pro"

Para gerar imagens de alta qualidade, não escreva apenas "um gato". Tente seguir esta estrutura:

[Objeto/Sujeito] + [Ação/Contexto] + [Estilo Artístico] + [Iluminação/Câmera] + [Parâmetros]

Exemplo:

/imagine prompt: A majestic lion wearing a golden crown, sitting on a throne in a dark forest, cinematic lighting, hyper-realistic, 8k --ar 16:9

Parâmetros

Parâmetros são "códigos" que você adiciona ao final do prompt (sempre começando com dois hífens --) para mudar o formato ou comportamento da imagem:

  • Proporção:--ar define o formato.--ar 16:9(Cinema/Youtube). --ar 9:16(Stories/TikTok). --ar 3:2(Fotografia clássica)
  • Caos: --c varia de 0 a 100. Valores altos geram resultados mais abstratos e inesperados.
  • Estilização: --s varia de 0 a 1000. Quanto maior, mais "artística" e menos literal será a imagem.
  • Negativo: --no para remover coisas. Ex:--no clouds (para um céu sem nuvens).

Dicas de Ouro

  • Seja específico, não longo: O Midjourney valoriza palavras fortes. Em vez de "muito grande", use "gigantic" ou "monumental".
  • Use as variações: Quando a IA gerar as 4 imagens, você verá botões: V1, V2, V3, V4 crie variações de uma das imagens. E U1, U2, U3, U4 faça o "Upscale" (aumenta a resolução) da imagem escolhida.
  • Inglês é melhor: Embora ele entenda português básico, a IA foi treinada majoritariamente em inglês. Se precisar, use um tradutor para os prompts.
